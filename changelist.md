# Changelist

## 2026-11-19

- Added dedicated Enchantments, Collectibles, and Notes pages.
- Added dated notes with names, descriptions, optional line-based checklists, completion dates, and hidden status.
- Added checklists for all 19 smithing templates and 22 current music discs, including in-game locations.
- Added Java/Bedrock edition and Minecraft version selectors that filter unavailable gear, enchantments, and collectibles.
- Added per-item crafting, smithing, and Netherite upgrade material checklists.
- Added completion badges for armor, weapons, tools, collectibles, and the full checklist, plus progress milestones.
- Added an anvil cost planner that adjusts the guide's sequence for prior work on the target item.
- Added the Survival/Adventure 39-level per-operation limit, with "Too Expensive!" warnings from 40 levels onward.
- Added JSON backup export and restore for checklist progress, notes, custom item copies, item visibility/order, and profile preferences.
- Added independent gear copies for tracking alternate enchantment choices, with optional custom names.
- Added Hidden tabs for gear and collectibles; original items can be hidden and restored, while duplicate gear copies can also be deleted.
- Added drag-and-drop ordering, with keyboard arrow-key alternatives.
- Added a visible language label to match the edition and version pickers.
- Renamed the app to Collectible Minecraft Companion (CMC) and renamed the npm package.
- Expanded the bilingual glossary and added a "Made by minCoding404" footer credit.
- Removed Minecraft Wiki source links and added the Minecraft/Mojang/Microsoft disclaimer to the footer.
- Added an accessible infrastructure overview covering application flow, browser storage, external resources, and accessibility practices.
- Updated the README with the new features and collectible locations.
